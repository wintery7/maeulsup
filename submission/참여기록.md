## 어떤 서비스인가

가족 여행 가는 곳 근처의 전통마을숲 이야기를, 가는 길 차 안에서 아이에게 1분 안팎의 음성으로 들려주는 웹서비스.

- 도착지를 고르면 60km 안의 숲 이야기를 가까운 순으로 최대 20편 이어서 들려준다.
- 이야기는 어린이용과 어른용 두 가지 말투. 음성은 MP3라 휴대폰 화면이 꺼져도 재생된다.
- 숲 기록 1,106건 중 주소로 위치를 찾은 882곳을 지도에 표시하고, 이야기를 만들 만한 기록이 있는 104곳에 이야기와 음성을 붙였다.
- 숲 사진 12장 (한국관광공사 6, 국가유산청 6). 공공누리 유형을 사진마다 확인했다.
- 개발자 키트: 정리한 데이터(CSV·JSON·GeoJSON)와 API 호출 예제. https://maeulsup.vercel.app/#kit

## 활용 데이터

- 산림청_전통마을숲위치도(산림공간정보 1:25000)_GW — API
- 산림청_숲에 사는 식물 정보 — 파일(CSV)
- 함께 쓴 것: 한국관광공사 TourAPI, 국가유산청 공개 API (사진), 카카오 로컬 API (주소 → 좌표), OpenStreetMap (지도)

## 만든 방법

- 정적 사이트 (Vercel). 서비스 중에 실시간 AI 호출이 없다. 이야기와 음성은 미리 만들고 검증을 통과한 것만 올렸다.
- 이야기: OpenAI gpt-5-mini로 원문을 아이 눈높이로 다시 쓰고, 같은 모델이 문장마다 원문 근거를 대조해 판정. 원문에 없는 사실이 있으면 탈락.
- 음성: Google Cloud TTS Chirp 3 HD.
- 공모 적격 기준의 "허위 내용이 아닐 것"을 지키려고, 통과율을 올리려고 판정 기준을 느슨하게 하지 않았다.

## 개선 아이디어로 낸 것 (21번, 2,000자 제한)

1. 역사·문화 조사 글이 255바이트에서 잘림 (142건, 식물이야기설명 179건 전부 50바이트)
2. '위치도'인데 좌표가 없고 주소 형식이 제각각
3. 빈 값이 공백 한 칸으로 옴, 중복 설명 18묶음 72건, 깨진 글자
4. 면적 단위가 명세와 다름, 필드명이 약어, 수종명이 데이터마다 다름
5. API는 XML만, CSV는 CP949
6. 사진 필드와 다른 기관 데이터와 잇는 식별자가 없음 (104곳 중 사진을 찾은 곳 12곳)
