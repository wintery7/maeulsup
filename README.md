# 마을숲, 어디까지 들어봤니?

가족 여행 가는 곳 근처에 있는 전통마을숲 이야기를, 가는 길 차 안에서 아이에게 들려주는 웹서비스다.
산림청 「산림공공데이터 어디까지 써봤니」 활용사례 공모(서비스형 + 개선 아이디어)에 내려고 만들었고, 2026년 11월 20일에 제출했다.

서비스: https://maeulsup.vercel.app

## 왜 만들었나

전통마을숲은 마을 사람들이 바람을 막고 마을을 지켜 달라고 빌며 오래 가꿔 온 숲이다. 산림청이 전국 1,106곳의 역사와 문화를 조사해서 공공데이터로 열어 두었는데, 거의 쓰이지 않는다.

직접 받아 보니 이유를 알 것 같았다. 글은 150자 안팎에서 잘려 있고, '위치도'인데 좌표가 없고, 빈 값은 공백 한 칸으로 온다. 쓰고 싶어도 손이 많이 가는 데이터다.

그래도 내용은 좋았다. 1585년쯤 남강 쪽 바람을 막으려고 마을 입구에 가꾼 숲, 바닷바람을 막으려고 500여 년 전부터 해송을 심어 온 바닷가 마을 숲 같은 이야기가 들어 있다. 이걸 아이가 들을 수 있는 말로 옮기면 여행 가는 길이 조금 더 재밌어지지 않을까 했다.

## 어떻게 쓰나

1. "어디로 가세요?"에 도착하는 시·군을 적는다. (예: 진도군, 진주)
2. 도착지에서 60km 안에 있는 숲 이야기가 가까운 순으로 최대 20편 나온다. "처음부터 이어서 듣기"를 누르면 한 편씩 이어서 재생된다. 한 편이 40초 안팎이라 도착 15분쯤 전에 틀어 두면 된다.
3. 음성은 MP3 파일이라 휴대폰 화면을 꺼도 계속 나온다. 듣기 시작하면 남은 음성을 미리 받아 두기 때문에 시골길에서 신호가 끊겨도 이어진다.
4. 이야기 끝에는 "도착하면 이팝나무를 찾아볼까요?" 같은 한마디가 붙는다. 가서 직접 찾아보라는 뜻이다.
5. 마음에 드는 숲이 있으면 길찾기로 가 보면 된다.

'지금 있는 곳 근처' 버튼을 누르면 휴대폰 위치로 가까운 이야기를 찾는다. 위치는 거리 계산에만 쓰고 어디로도 보내지 않는다.

말투는 '아이와 듣기'와 '어른 해설' 두 가지다. 모든 이야기 아래에서 산림청 원문을 펼쳐 볼 수 있다.

숲 기록 1,106건 중 주소로 위치를 찾은 882곳을 지도에 표시했고, 이야기를 만들 만한 기록이 있는 104곳에 이야기와 음성을 붙였다.

## AI가 지어내지 않게 한 방법

아이에게 들려주는 이야기라 틀린 내용이 들어가면 안 됐다. 그래서 이야기는 서비스에서 실시간으로 만들지 않고, 미리 만들어 검증을 통과한 것만 올렸다. 서비스에는 AI 호출도, 서버 코드도 없다.

- 잘린 원문은 끊긴 마지막 문장을 먼저 잘라냈다. AI가 끊긴 뒤를 상상으로 잇지 못하게.
- AI가 문장마다 근거가 된 원문 구절을 같이 내게 했다. 그 구절이 원문에 실제로 있는지 코드로 확인한다.
- 이야기에 나온 숫자와 나무 이름, 지명이 그 숲의 원문에 있는지 코드로 대조한다. 숲 기록에 나오는 수종 표기 1,699개를 사전으로 만들어 두고, 원문에 없는 이름이 섞이면 떨어뜨린다.
- 이야기를 쓴 호출과 따로, 다른 호출로 문장마다 원문에 근거가 있는지 다시 판정한다.
- 떨어지면 무엇이 문제였는지 알려 주고 다시 쓰게 한다. 그래도 안 되면 원문을 거의 그대로 옮긴 문구로 대신한다.

104편 중 69편이 한 번에 통과했고, 35편은 다시 써서 통과했다. 원문 문구로 대신한 이야기는 없다. 자세한 수치는 서비스의 '데이터 이야기' 페이지와 [docs/data-report.md](docs/data-report.md)에 있다.

이야기는 OpenAI gpt-5-mini로 만들고 판정했고, 음성은 Google Cloud TTS(Chirp 3 HD)로 만들었다.

## 데이터를 쓰며 걸린 것들

자세한 내용과 숫자는 [docs/data-report.md](docs/data-report.md)에 정리했다. 짧게 쓰면 이렇다.

- 역사·문화 조사 글 142건이 한글 인코딩 기준 253~254바이트에서 잘린다. DB 칸이 255바이트인 것 같다. 같이 쓴 식물 정보도 179건 전부 50바이트 근처에서 잘린다.
- 좌표가 없어서 주소로 위치를 찾았다. 그런데 주소가 '전북', '전라북도'로 섞여 있고 시·군이 빠진 것도 있다. 1,106곳 중 224곳은 끝내 위치를 찾지 못했다.
- 빈 값이 공백 한 칸으로 온다. 처음엔 이걸 몰라서 빈 값이 0%로 나왔다.
- 다른 숲인데 설명이 똑같은 기록이 18묶음 72건 있다.
- 면적 값이 명세의 단위와 안 맞아 보여서 화면에 쓰지 않았다.
- 사진 필드가 없고, 다른 기관 데이터와 이어 줄 식별자도 없다.

산림청에 낸 개선 의견도 이 내용을 바탕으로 썼다.

## 숲 사진

마을숲 데이터에는 사진이 없어서 한국관광공사 TourAPI와 국가유산청 공개 API에서 찾았다. 이름이 맞아도 숲이 아니라 근처 절터나 담장을 찍은 사진이 많았다. 그런 사진을 숲 사진처럼 붙이면 틀린 정보가 되니까, 사진을 하나하나 보고 숲이 찍힌 것만 골랐다. 그래서 104곳 중 12곳에만 사진이 있다 (관광공사 6장, 국가유산청 6장).

사진마다 공공누리 유형을 확인했다. 제3·4유형은 변경금지라 원본 그대로 두고 자르지 않는다. 홈 화면처럼 사진을 잘라 쓰는 곳에는 제1유형만 쓴다.

## 개발자 키트

이 데이터를 쓰려는 사람이 같은 수고를 반복하지 않게 정리한 데이터와 코드를 [kit/](kit/) 폴더에 두었다. 빈 값을 정리하고 시·군을 분리하고 좌표를 붙였고, 글이 잘렸는지와 중복인지도 표시했다. CSV, JSON, GeoJSON이 있고 API 호출 예제(Python, JavaScript)도 있다. 서비스의 [개발자 키트](https://maeulsup.vercel.app/#kit) 페이지에서도 바로 내려받을 수 있다.

## 폴더

```
pipeline/   데이터 받기부터 정리, 위치 찾기, 이야기, 검증, 음성, 사진까지 (Python)
web/        서비스 화면 (HTML, CSS, JavaScript만 씀. 빌드 과정 없음)
kit/        개발자 키트
docs/       데이터 진단 리포트
data/raw/   산림청에서 받은 원본
data/work/  중간 결과와 검증 기록
submission/ 공모 제출 문안
```

직접 돌려 보는 방법은 [HOW_TO_RUN.md](HOW_TO_RUN.md)에 있다. 데이터 때문에 막혔던 일은 [FRICTION_LOG.md](FRICTION_LOG.md)에 그때그때 적었다.

## 만들면서 겪은 일

처음엔 우리 동네 숲 이야기를 들려주는 서비스를 생각했다. 그런데 데이터를 열어 보니 이야기가 넉넉한 숲이 전남, 경남, 경북, 전북에 몰려 있고 서울·인천에는 하나도 없었다. 그래서 "여행 가는 곳의 숲"으로 방향을 바꿨다.

퀴즈 기능도 넣으려다 뺐다. 차 안에서는 운전하는 부모도, 화면을 안 보는 아이도 버튼을 누를 수 없다. 대신 이야기 끝에 "도착하면 찾아볼 것"을 한마디 붙였다.

음성은 처음에 브라우저 음성으로 하려 했는데, 휴대폰 화면이 꺼지면 멈추는 경우가 많았다. 거치대에 두고 듣는 상황에 안 맞아서 음성 파일을 미리 만들었다.

판정 AI를 처음엔 gpt-4o-mini로 했더니 샘플 10편 중 한 편도 통과하지 못했다. 원문에 그대로 있는 "2,000평"을 없다고 하고, 도착하면 무엇을 찾아보자는 권유 문장까지 떨어뜨렸다. 판정 모델을 gpt-5-mini로 바꾸고, 권유 문장은 형식이 아니라 무엇을 찾자는 건지만 보게 했다. 원문에 없는 사실은 지금도 떨어진다.

근거 구절 대조도 처음엔 글자 하나만 달라도 떨어뜨렸다. "알려져 왔기"를 "알려져 있기"로 옮겨 적은 한 글자 때문에 이야기 전체가 탈락했다. 그래서 20자 이상 구절은 90% 이상 같으면 인정하게 바꿨다. 숫자는 지금도 정확히 같아야 한다.

104편을 다 만들고 읽어 보니 99편이 같은 문장으로 시작했고, 39편에는 아이가 모를 말이나 면적, 괄호가 남아 있었다. 다 다시 만들지 않고, 사실이 없는 시작 문장은 코드로만 빼고, 어려운 말이 남은 이야기만 다시 만들었다.

이야기 한 편이 40초 안팎으로 짧다. 원문이 짧아서다. 길게 늘리면 원문에 없는 말이 들어가니 늘리지 않고, 대신 도착지 근처 이야기를 여러 편 이어 붙였다.
