# 마을숲, 어디까지 들어봤니?

가족 여행 가는 곳 근처에 있는 전통마을숲 이야기를, 가는 길 차 안에서 아이에게 들려주는 웹서비스다.
산림청 「산림공공데이터 어디까지 써봤니」 활용사례 공모에 내려고 만들었다.

서비스: [배포 주소]

## 왜 만들었나

전통마을숲은 마을 사람들이 바람을 막고 마을을 지켜 달라고 빌며 오래 가꿔 온 숲이다. 산림청이 전국 1,106곳의 역사와 문화를 조사해서 공공데이터로 열어 두었는데, 활용신청이 몇십 건에 그칠 만큼 거의 쓰이지 않는다.

직접 받아 보니 이유를 알 것 같았다. 글은 150자 근처에서 잘려 있고, '위치도'인데 좌표가 없고, 빈 값은 공백 한 칸으로 온다. 쓰고 싶어도 손이 많이 가는 데이터다.

그래도 내용은 좋았다. 1585년쯤 남강 바람을 막으려고 마을 사람들이 함께 이팝나무를 심었다는 숲, 바닷바람을 막으려고 400여 년 전부터 해송을 가꿔 온 섬마을 숲 같은 이야기가 들어 있다. 이걸 아이가 들을 수 있는 말로 옮기면, 여행 가는 길이 조금 더 재밌어지지 않을까 했다.

## 어떻게 쓰나

1. "어디로 가세요?"에 도착하는 시·군을 적는다. (예: 진도군, 진주)
2. 그 근처 마을숲 이야기가 차례로 나온다. "처음부터 이어서 듣기"를 누르면 한 편씩 이어서 재생된다. 화면을 꺼도 계속 나온다.
3. 이야기 끝에는 "도착하면 이팝나무를 찾아볼까요?" 같은 한마디가 붙는다. 가서 직접 찾아보라는 뜻이다.
4. 마음에 드는 숲이 있으면 길찾기로 가 보면 된다.

말투는 '아이와 듣기'와 '어른 해설' 두 가지다. 모든 이야기 아래에서 산림청 원문을 펼쳐 볼 수 있다.

## AI가 지어내지 않게 한 방법

아이에게 들려주는 이야기라 틀린 내용이 들어가면 안 됐다. 그래서 이야기는 서비스에서 실시간으로 만들지 않고, 미리 만들어 검증을 통과한 것만 올렸다.

- 잘린 원문은 끊긴 마지막 문장을 먼저 잘라냈다. AI가 끊긴 뒤를 상상으로 잇지 못하게.
- AI가 문장마다 근거가 된 원문 구절을 같이 내게 했다. 그 구절이 원문에 실제로 있는지 코드로 확인한다.
- 이야기에 나온 숫자와 나무 이름, 지명이 그 숲의 원문에 있는지 코드로 대조한다. 다른 숲 기록에 나오는 이름 1,700여 개를 사전으로 만들어 두고, 원문에 없는 이름이 섞이면 떨어뜨린다.
- 이야기를 쓴 AI와 따로, 다른 호출로 문장마다 원문에 근거가 있는지 다시 판정한다.
- 떨어지면 무엇이 문제였는지 알려 주고 다시 쓰게 한다. 두 번 더 해도 안 되면 원문을 거의 그대로 옮긴 문구로 대신한다.
- 마지막으로 이야기를 만들지 않은 팀원이 표본을 원문과 나란히 놓고 직접 검수했다.

검증 수치는 서비스의 '데이터 이야기' 페이지와 [docs/data-report.md](docs/data-report.md)에 있다.

## 데이터를 쓰며 걸린 것들

자세한 내용과 숫자는 [docs/data-report.md](docs/data-report.md)에 정리했다. 짧게 쓰면 이렇다.

- 역사·문화 조사 글이 한글 인코딩 기준 253~254바이트에서 잘린다. DB 칸이 255바이트인 것 같다. 같이 쓴 식물 정보도 50바이트에서 잘린다.
- 좌표가 없어서 주소로 위치를 찾았다. 그런데 주소가 '전북', '전라북도'로 섞여 있고 시·군이 빠진 것도 있다.
- 빈 값이 공백 한 칸으로 온다. 처음엔 이걸 몰라서 빈 값이 0%로 나왔다.
- 다른 숲인데 설명이 똑같은 기록이 72건 있다.
- 면적 값이 명세의 단위와 안 맞아 보인다.

산림청에 낸 개선 의견도 이 내용을 바탕으로 썼다.

## 개발자 키트

이 데이터를 쓰려는 사람이 같은 수고를 반복하지 않게 정리한 데이터와 코드를 [kit/](kit/) 폴더에 두었다. 빈 값을 정리하고 시·군을 분리하고 좌표를 붙였고, 글이 잘렸는지와 중복인지도 표시했다. 서비스의 '개발자 키트' 페이지에서도 바로 내려받을 수 있다.

## 폴더

```
pipeline/   데이터 받기부터 검증, 음성까지 (Python)
web/        서비스 화면 (HTML, CSS, JavaScript만 씀. 빌드 과정 없음)
kit/        개발자 키트
docs/       데이터 진단 리포트
data/raw/   산림청에서 받은 원본
```

직접 돌려 보는 방법은 [HOW_TO_RUN.md](HOW_TO_RUN.md)에 있다.

## 만들면서 겪은 일

<!-- 민재: 아래는 초안이야. 실제로 겪은 걸로 고쳐 써 줘. -->

처음엔 우리 동네 숲 이야기를 들려주는 서비스를 생각했다. 그런데 데이터를 열어 보니 이야기가 넉넉한 숲이 전남, 경남, 경북, 전북에 몰려 있고 서울·인천에는 하나도 없었다. 그래서 "여행 가는 곳의 숲"으로 방향을 바꿨다. 남쪽 가족 여행과 오히려 잘 맞았다.

퀴즈 기능도 넣으려다 뺐다. 차 안에서는 운전하는 부모도, 화면을 안 보는 아이도 버튼을 누를 수 없다. 대신 이야기 끝에 "도착하면 찾아볼 것"을 한마디 붙였다.

음성은 처음에 브라우저 음성으로 하려 했는데, 휴대폰 화면이 꺼지면 멈추는 경우가 많았다. 거치대에 두고 듣는 상황에 안 맞아서 음성 파일을 미리 만들었다.
